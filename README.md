# WEB2 Final Project

Database deliverables for the Modern Movie Discovery & Social Platform project.

## Stack

- PHP with Laravel using MVC
- MySQL database

## Database task

This repository contains the database layer for the assigned objectives: user authentication, the movie catalogue with TMDB data, and the API integrations named in the project brief. See database/README.md for migration setup and integration boundaries. The Word report is in docs/Database_Design_Task_2.docx.
